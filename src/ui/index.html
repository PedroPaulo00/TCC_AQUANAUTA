Sobre o Aquanauta

Aquanauta

Versão 1.0.0

2026

Aplicação desktop para promover o bem-estar do usuário durante o uso prolongado do computador.

O Aquanauta monitora sua atividade e gera lembretes inteligentes para hidratação, alongamento, descanso dos olhos e pausas.

Funcionalidades

  • Monitoramento de atividade em tempo real
  • Sistema Pomodoro configurável
  • Alertas de hidratação, alongamento e descanso
  • Temporizadores personalizados
  • Mascote interativo

Tecnologias

  • Electron (framework desktop)
  • Node.js + npm (runtime e pacotes)
  • HTML5 + CSS3 + JavaScript (ES6+)
  • IPC (comunicação processo principal / renderer)
  • localStorage API (persistencia de dados)
  • CSS Glassmorphism — estetica Frutiger Aero / Windows Vista
